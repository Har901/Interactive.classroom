INTERACTIVE CLASSROOM — prototype

Files:
- index.html
- style.css
- app.js

How to run:
1. Keep all three files in the same folder.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. No installation or server is required for the prototype.

What is included:
- Main landing page with black/gold/blue visual style.
- Intro/about-style content using the supplied wording.
- Questioning section with Physics and Chemistry guided educational chat.
- Simulation section with Modeling guide and interactive orbital simulation.
- Defending Article page.
- Back navigation and website search.
- Responsive mobile layout.

AI note:
The “AI guide” in this version is a local educational prototype (rule-based), so it does not send anything to an AI provider or require an API key. A real AI model can be connected later.
